LLM Wiki に質問し、出典つきで答える。

- vault の場所は次の順で決める。
  1. 作業フォルダに `HARNESS.md` があり、その「環境」節に「wiki の clone 先」の行があれば、その値(作業フォルダからの相対パス)。チームで配る形。
  2. 無ければ `{{VAULT}}`(個人の vault。配る側でパスに置き換える)。
  どちらも無ければ、vault の場所を人に聞いて止まる。
- vault が読めない(作業フォルダの外で許可されていない)ときは、vault を読めるように起動し直すよう人に伝えて止まる(例: `--add-dir <vault>`)。シェルで無理に読みにいかない。

## 手順

1. vault の `AGENTS.md`(規約)を読む。以降はその規約に従う。
2. 規約の「Query」の手順で答える(`index.md` → 関係するページ → 必要なら `raw/`)。ページ名を出典として挙げ、wiki に無いことは「無い」と答える。
3. vault には書き込まない。格納したい知見があれば、人に「格納する知見はある?」で取り込めることを伝えるだけにする。
