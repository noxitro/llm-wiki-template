# 参考スキル

LLM Wiki を読み書きするスキルの**参考実装**。このリポジトリから直接は導入しない。
使う側で、自分のマーケットプレイス(プラグイン)にコピーして調整する前提で置いている。

| スキル | いつ使うか | vault に書くか |
| --- | --- | --- |
| `wiki-ingest` | 「格納する知見はある?」「wiki に取り込んで」 | 書く(人の承認の後だけ) |
| `wiki-query` | 「wiki に聞いて」 | 書かない |
| `wiki-lint` | 「wiki を点検して」 | 書く(人の承認の後だけ) |

## コピーするときに直すところ

- vault の場所は、スキルの本文に書いた順で決まる: 作業フォルダの `HARNESS.md` の「環境」節にある「wiki の clone 先」の行があればそれ、無ければ `{{VAULT}}`。
  - **個人で使う**: 本文の `{{VAULT}}` を、vault を clone したパスに置き換える。プラグインの側でパスを解決する仕組み(設定ファイルなど)があるなら、そちらに合わせて書き換える。
  - **チームで配る**: `{{VAULT}}` の行を消し、`HARNESS.md` の行だけを残す。各作業リポジトリの `HARNESS.md` に `- wiki の clone 先: ../<vault 名>` の 1 行を書けば、スキル本文にパスを埋めずに済む(配布物に PC 固有のパスが入らない)。チーム用の書き方は README の「チームで使う」にある。
- スキルの手順は「vault の `AGENTS.md` を読み、それに従う」形にしてある。規約の中身はスキルに写さず、vault 側の `AGENTS.md` だけを直す(スキルと規約が別々に変わっていくのを防ぐため)。
- 機械の点検は vault の `scripts/wiki_lint.py` を呼ぶだけにしてある。点検の項目もスキルに写さない。
