# グローバルナレッジWiki(Copilot CLI用グローバル指示の雛形)

<!--
使い方: このファイルを `%USERPROFILE%\.copilot\copilot-instructions.md` にコピーし、
下記のパスを実際のwiki配置場所に書き換える。
これにより、どのディレクトリで copilot を起動しても自動参照が有効になる。
-->

`C:\path\to\llm-wiki` に、LLMエージェントが維持するナレッジwikiがある(規約は同リポジトリのAGENTS.md)。

- **参照**: 新しい技術課題・調査・設計判断に着手するとき、その話題を過去に扱った可能性があれば、まず `C:\path\to\llm-wiki\index.md` を読む(1画面程度の軽いカタログ)。該当ページがあれば精読して知見を前提に組み込み、出典としてページ名を挙げる。該当がなければ何も言わず続行してよい。
- **書き込み**: wikiへの取り込み・点検は AGENTS.md のワークフロー(ingest / query / lint)に厳密に従う。通常作業の傍らで勝手にwikiを書き換えない(取り込みたい知見が出たら、ユーザーに提案して承認を得る)。
- パスがアクセス許可外の場合は、`--add-dir C:\path\to\llm-wiki` を付けた起動をユーザーに案内する。
